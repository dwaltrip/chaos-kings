## 2. The reframe

One-paragraph pointer — full story in [4.10-6](4.10-6-prefix-sets-and-lanes-reframed.md).

The key shift: the "perfect start" problem decomposes into two mostly-independent sub-problems — **opening (prefix)** and **main expansion (lanes)** — with a small interface between them (prefix tips = lane starting positions). Under that decomposition, a prefix is "good" iff it lands at a tile from which a lane of the required length can be constructed. So prefix-side and lane-decomp-side heuristic work unify under a single per-tile "lane-entry quality" layer — **one body of work serves both sub-problems**. The heuristic progress from session 2 is no longer "half the solver"; it's progress on the shared scoring layer that both halves need.

## 3. What we built

- **New module:** `starting-region/` — BFS-bounded tile set near the general, with per-tile topological annotations (distance field, outward divergence, outward straight-ray depth, articulation points + bridges)
- **Reusable infra scan first** — most of what we needed already existed in `utils/` (Tarjan, board rendering, walkable-neighbor helpers). Net new code was small: a distance-field BFS helper, a crop helper extracted from the board renderer, and a scoped-Tarjan variant for induced subgraphs
- **Debug runner** dumps annotated ASCII overlays for the 7 session-2 boards, with a CLI substring filter for zooming on one board at a time
- **Two commits:** `c2ac76f2` (phase 1 BFS + annotations), `b7752ccf` (cleanups + boundary filter)

## 4. Boundary-artifact filter

- First sanity-check pass surfaced noisy articulation-point output on open boards — scoped Tarjan was flagging tiles that look like chokes only because the BFS radius cutoff creates boundary fingers with nowhere to loop back to
- **Fix:** intersect the scoped-subgraph Tarjan result with the full-board Tarjan result. A tile is a real choke iff it's an articulation point on *both*
- Clean property: the intersection equals "full-board articulation points that happen to lie within the starting region" — principled, no tunable threshold, preserves real chokes even when they sit near the BFS boundary
- Correctness confirmed by visual spot checks on the 3 highest-signal boards

## 5. Spot-check highlights

**Most encouraging finding:** `tight-corner-1`'s chute — the one case [session 2](4.10-3-lane-decomp-session-2-findings.md) identified as genuinely structurally hard — is identifiable **purely from topology**. The bridges list from a scoped Tarjan analysis names the exact chute tiles session 1's oracle flagged. No lane decomposition required. This is the concrete proof-of-concept referenced in [4.10-6](4.10-6-prefix-sets-and-lanes-reframed.md).

**Structural taxonomy of "tight" boards fell out:**

| Board | Real APs | Tightness type |
|---|---|---|
| `pocket-11x11` | 0 | tight-by-shape (bounded pocket, no formal chokes) |
| `scattered-pockets-13x13` | 29 | tight-by-tube (nearly every tile is a choke) |
| `tight-corner-1` | 19 | tight-by-chute (selective but critical chokes) |

These aren't just different numbers — they map onto session 2's different empirical failure modes, and they suggest different prefix strategies may suit different types.

**Other observations:**
- Tarjan alone isn't sufficient — `pocket-11x11` has 0 articulation points despite being visually constrained. The structural signal there comes from outward divergence, not from chokes. Reinforces the multi-signal scorer intuition
- Filter survival rate is itself a meta-signal: 47% on `fairly-open` (mostly scoping artifacts) vs. 100% on `sparse-mtns-11x11` (all real) — indicates whether a board is tight throughout or mostly-open-with-localized-pinches

## 6. Known limitations / loose ends

- **Dead-end nook articulations** — many real APs on open boards correspond to single-tile dead-ends. Not worth fixing directly; dissolves under multi-signal scoring (nooks also have low divergence and low ray depth)
- **`inwardCount`** annotation dropped in cleanup — wasn't carrying informational weight
- **Local perpendicular width** annotation was in the v1 brainstorm but not implemented
- **Reach-beyond count** (how much space is reachable from a tile without backtracking) deferred as expensive

## 7. Pointers for next session

1. **Per-tile tip scorer** — combine the annotations into a scalar "lane-entry quality" score. Turns this session's work into something actionable. Naturally absorbs the dead-end-nook issue
2. **Dumb prefix generator** targeting high-scoring tips. Closes the end-to-end loop: generator → scorer → feed to session 2 harness
3. **Re-run session 2 matrix** on generated (not random-walk) blobs. Key question: which failures were blob-pathology vs. genuine?
4. **Methodology:** the tight-by-shape / tight-by-tube / tight-by-chute taxonomy could become an axis in future evaluation matrices
