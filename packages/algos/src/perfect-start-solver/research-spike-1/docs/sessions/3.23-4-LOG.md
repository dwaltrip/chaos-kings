## What happened

Prefix set enumeration — the central experiment from the theory doc. For each (board, prefix depth, overlap pattern), enumerate all mutually compatible prefix assignments.

**Overlap pattern survey** — extracted unique overlap patterns from timing table (cap 20-24). At low captures it's the full combinatorial space; at cap=24, timing heavily filters (37 of 256 patterns at N=5).

**Prefix set enumeration experiment** — 8 boards × D=3,4 × all overlap patterns. Per-pattern counts are moderate on hard boards (median ~20-24 at N=5). See `3.23-4-prefix-set-initial-exploration.md` for full data.

**Dead-tip analysis** — 78-100% of prefix sets on constrained boards are geometrically self-defeating (a tip has free=0 when accounting for tiles claimed by other prefixes). Key caveat: short bursts fully within the prefix don't need free tips, so this overstates the problem.

**Visualization tooling** — `getPrefixSets()` helper, `formatPrefixSet()` with board grid (`*` for shared tiles), crop parameter, `show-prefix-sets` CLI.
