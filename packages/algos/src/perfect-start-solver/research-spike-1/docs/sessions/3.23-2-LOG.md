### Theory doc

Wrote `docs/PREFIX-STRUCTURE-THEORY.md` — a working theory about how near-general path prefix structure can dramatically reduce the solver's search space. Key ideas:

- **Prefix sets**: a small collection of short paths (length 3-4) from the general, one per burst, that are mutually compatible. Conjectured to be tens to low hundreds per board.
- **"Opens up" property**: good prefixes lead to non-crossing trajectories where bursts can extend freely. Width as a proto-metric for how many parallel bursts a region supports.
- **Overlap as prefix parameterization**: overlap budget controls where bursts diverge. Multiple overlap bursts tightly couple the prefix set, narrowing possibilities.
- **The decomposition**: enumerate prefix candidates → build compatible sets → check trajectory independence → match timing entries → extend suffixes.
- **Short suffix insight**: most bursts (all but B1) have short or zero suffixes at prefix depth 3-4, so suffix independence mostly only matters for the longest burst.
- **Two separable claims**: (1) prefix structure reduces search space (holds even with partial suffix interaction), (2) suffixes don't interact (full independence win, not required for claim 1).
