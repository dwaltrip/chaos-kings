## Burst pattern ideas

**NOTE:** These patterns dont' specify the length! they just specify the first several moves and then say "do X until done". We can iterate over all possible lengths that fit the specified opening moves.        

### Idea 1

* Burst 1: LEFT x 4, then UP for the rest
* Burst 2: LEFT until done
* Burst 3: LEFT, DOWN, then LEFT until done
* BURST 4: DOWN, DOWN, then LEFT until done (might only have enough for down part)

### Idea 2

* Burst 1: same as above
* Burst 2: LEFT, LEFT, DOWN, LEFT until done
* Burst 3: LEFT, DOWN, DOWN, LEFT until done
* Burst 4: DOWN, DOWN
