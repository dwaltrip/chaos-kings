### Key framings emerged

- **Board structure vs path structure**: two complementary lenses. Board structure = terrain properties. Path structure = candidate set properties (clustering, conflict density, diversity). Path structure is also another angle on search space reduction.
- **Non-backtracking paths and tree structure**: self-avoiding walks are more tree-like than the review assumed. Early branching is "sticky." Partially rehabilitates tree-based reasoning as an analytical tool.
- **Greedy strategies**: useful as both exploration tools and potential sub-components of solver techniques (e.g., greedy bounds for feasibility pruning).

## Key learnings

- **The spatial/structural direction is not dead** — the experiments so far were a small slice. Broader approaches (sector decomposition, bottleneck detection, constraint propagation) remain untested and promising.
- **Board structure and path structure are complementary lenses** — most powerful optimizations probably exploit both.
- **The capture-target waste is the most concrete identified optimization** — but its magnitude is unknown without per-target timing (A1).
- **Watched literals (D11) may be the highest-impact single thread** for search improvement — replaces O(all candidates) scanning with event-driven invalidation.
- **The board structure body of work needs careful scoping** — rich territory but risk of rabbit holes. The 3-layer decomposition helps make it plannable.
